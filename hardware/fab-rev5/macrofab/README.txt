IMSPI 8080 - rev5 MacroFab package
==================================
Board:  204.1 x 112.1 mm, 4-layer (F/In1/In2/B), FR4, 1 oz outer /
        0.5 oz inner, min track 0.15 mm / min clearance 0.127 mm,
        via 0.6/0.3 (one 0.5/0.25 blind pair). No impedance requirements.
        12 PCB-void-mounted through-hole toggles (8x MTS-102 latching,
        4x MTS-103-M momentary).

UPLOAD SET (drag each onto the matching step in the MacroFab wizard)
  1. Fab data (PCB + stackup + drill, preferred):
       imspi8080_rev5-odb.zip           (ODB++, generated by KiCad 10)
     Fallback if ODB ingest complains:
       imspi8080-rev5-gerbers.zip       (RS-274X + Excellon PTH/NPTH + gbrjob)
  2. BOM:  imspi8080-rev5-bom-macrofab.csv  (or the .xlsx, same content)
     Columns: Designator, Name/Description, Manufacturer, MPN, Quantity,
     Footprint, Notes. Manufacturers filled where unambiguous; passives
     carry value/size specs for MacroFab's part matcher.
  3. Pick & place: imspi8080-rev5.xyrs
     Columns: RefDes, X(mm), Y(mm), Rotation, Side, Value, Footprint.
     Board origin = KiCad origin (top-left of the 204.1 x 112.1 outline,
     absolute coords from the .kicad_pcb).

ASSEMBLY NOTES (same as the JLCPCB package, fab-rev5/README.txt)
  - Two post-assembly wires are REQUIRED (documented opens, intentional):
      1. HC_QH:  ~45 mm 30 AWG wire, U1 pin 12 -> U6 pin 9.
      2. TLC_SCLK: ~10 mm wire, via at (124.32, 94.60) -> stub (124.64, 102.34).
  - J1-A6 (USB-C duplicate D+ pad) is intentionally unconnected.
  - Pre-fab netlist check: python3 ../check_opens.py  (kicad-cli drc does
    NOT report unconnected nets on this board - see ../check_opens.py header).

KiCad source (imspi8080_rev5.kicad_pcb/.kicad_pro/.kicad_sch) is in the
parent directory; gerbers regenerate with kicad-cli (see parent README.txt).
